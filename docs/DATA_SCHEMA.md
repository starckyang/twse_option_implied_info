# DATA_SCHEMA（M0 調查結果）

調查日期：2026-11-09。以下皆為實測，標「未驗證」者代表還沒測。

## 1. 選擇權每日行情下載

- 頁面：`https://www.taifex.com.tw/cht/3/dlOptDailyMarketView`
- 端點：`POST https://www.taifex.com.tw/cht/3/dlOptDataDown`
- 表單參數（`application/x-www-form-urlencoded`，不需 cookie / token）：

| 參數 | 值 |
|---|---|
| `down_type` | `1` |
| `commodity_id` | `TXO` |
| `commodity_id2` | 空字串 |
| `queryStartDate` / `queryEndDate` | `YYYY/MM/DD` |

```bash
curl -X POST https://www.taifex.com.tw/cht/3/dlOptDataDown \
  -d 'down_type=1&commodity_id=TXO&commodity_id2=&queryStartDate=2026/11/09&queryEndDate=2026/11/09'
```

- 編碼：**MS950（cp950，即 Big5 擴充）**，CRLF。每列結尾多一個逗號，pandas 要用 `index_col=False`。
- 區間上限：**不可超過一個月**（超過會回 HTTP 200 的 HTML，內容為 `alert("日期時間錯誤")`）。回補時要按月切段。
- 假日／無資料：HTTP 200，只有表頭、沒有資料列（約 200 bytes）。
- 錯誤也是 HTTP 200，所以不能只看狀態碼；要檢查第一行是否為預期表頭。
- 請求頻率限制：未測到限制（連續約 10 次無問題），仍建議回補時每次間隔 1–2 秒。
- 站點有 Cloudflare。從本機可正常下載；**從 GitHub Actions 是否被擋：未驗證**（需要 repo 後才能測）。

## 2. 欄位

| 欄位 | 說明 |
|---|---|
| 交易日期 | `YYYY/MM/DD` |
| 契約 | `TXO` |
| 到期月份(週別) | 見第 3 節 |
| 履約價 | 浮點數 |
| 買賣權 | `買權` / `賣權`（值可能有空白，要 strip） |
| 開盤價、最高價、最低價、收盤價 | 無成交為 `-` |
| 成交量 | 整數 |
| 結算價 | 每日結算價，幾乎每個序列都有值（深度價內買權也有） |
| 未沖銷契約數 | 無為 `-`或 0 |
| **最後最佳買價 / 最後最佳賣價** | **有。** 沒有報價為 `-`。調查日月選 `202611` 共 596 列，買價缺 92 列、賣價缺 141 列，**沒有出現 0**，缺值一律是 `-` |
| 歷史最高價、歷史最低價 | |
| 是否因訊息面暫停交易 | 通常空白 |
| 交易時段 | `一般` / `盤後`，**分列**（同一序列每個時段各一列） |
| 漲跌價、漲跌% | |
| 契約到期日 | `YYYYMMDD` 整數 |

**結論：有買賣價**，因此可以走官方 VIX 的中價做法，不必退回結算價。

## 3. 月選／週選

`到期月份(週別)` 欄位：

| 格式 | 例 | 意義 | 到期日 |
|---|---|---|---|
| `YYYYMM`（6 碼純數字） | `202611` | **月選** | 該月第三個星期三（`20261118`） |
| `YYYYMMWn` | `202611W2` | 週三到期週選 | 週三（`20261111`） |
| `YYYYMMFn` | `202611F2` | 週五到期週選 | 週五（`20261113`） |

規則：月選 = 欄位 strip 後符合 `^\d{6}$`（原始值帶尾端空白，如 `202611  `，所有字串欄位讀入後都要 strip）。到期日直接用 `契約到期日` 欄位，不必自己推算。
調查日有月選 202611、202612、202701、202703、202706。（季月 3、6 月較遠，1 月為非季月但有。）

## 4. 結算時間

官方手冊：最後結算時點為**到期日 13:30**。到期時間 T 要算到到期日 13:30。

## 5. 一般與盤後時段

- 分列。**VIX 計算只用「一般」時段**（官方手冊也是只用 TXO 一般交易時段報價）。
- 盤後列的「交易日期」是歸屬日期，**前一天下午 15:00 起就已經出現下一個交易日的盤後資料**。
  實測：2026/11/09 晚上 19:57 查 `2026/11/10`，已回 3444 列，且**全部是盤後**。
  → 判斷「當日資料是否已公布」要看是否有 `一般` 時段的列，不能只看有沒有列。

## 6. 官方 VIX（驗證基準）

- 編製方法：`https://www.taifex.com.tw/file/taifex/CHINESE/files/7/VIX_book.pdf`（36 頁；文字已抽出到 `docs/VIX_book_extracted.txt`）。
- 每日收盤值下載：`https://www.taifex.com.tw/file/taifex/Dailydownload/vix/log2data/YYYYMMnew.txt`（cp950，tab 分隔）。
  欄位：交易日期、時間（`13450000`＝13:45）、臺指選擇權波動率指數、收盤前1分鐘平均指數。
  例：`20261109  13450000  43.80  43.70`。
- **歷史深度只有最近約 3 個月**（202608–202611 為 200，202607 起為 302）。更長的歷史是否在別處：**未驗證**。
- 盤中逐日檔：`https://www.taifex.com.tw/cht/7/getVixData?filesname=YYYYMMDD`（每 15 秒一筆）。

### 官方方法與我們每日報表的差異（會造成小幅差距）

| 項目 | 官方 | 我們（每日收盤後） |
|---|---|---|
| 計算頻率 | 每 15 秒，收盤值為 13:45 的值 | 每日一次，用「最後最佳買賣價」 |
| 報價 | 15 秒快照＋EMA 價差異常值篩選與回補 | 只有每日的最後最佳買賣價，無法重現篩選 |
| 遠期價 F | **同月份 TX 期貨**最後成交價（無則用買賣中價），不是 put-call parity | put-call parity；或另抓 TX 期貨收盤價（期貨每日行情有同樣的下載頁） |
| 無風險利率 | 對應天期 **TAIBOR**（隔夜、1W、2W、1M、2M、3M）線性內插 | 需另找來源，**尚未決定** |
| 換月 | 近月距到期**剩 2 個交易日**起，改用次近月與次次近月（春節長假順延） | 同左，要自己實作交易日曆 |
| 截斷 | 離 K0 往外，連續兩個序列沒有買價即停止 | 同左 |
| T | 精確到秒；`525600` 分鐘＝1 年 | 分鐘，13:30 結算 |

## 7. 可行性初測（探索性，不是 M1 實作）

用 2026/11/09 一般時段月選資料，put-call parity 求 F，R 假設 1.5%，買賣價中價，連續兩個無買價截斷：

| | T | F | K0 | 序列數 | σ |
|---|---|---|---|---|---|
| 近月 202611 | 0.02466 | 41,440 | 41,400 | 283 | 47.89 |
| 次月 202612 | 0.10137 | 41,490 | 41,400 | 281 | 43.44 |

**自算 VIX ≈ 43.79，官方收盤 43.80（收盤前 1 分鐘平均 43.70）。**
這只是單日、單一利率假設的結果，不代表之後都能這麼接近，需靠 M2 的多日對照確認。
